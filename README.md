# HackClub OS
A pretty simple desktop UI that resembles an OS in the style of HACK CLUB :)

#Setup
If you want to edit this project and make it your own there are literally only three files, the main index.html, script.js, and style.css\
Mainly you will probably just need to change stuff in the html file to make small changes!

#Test
If you just want to see how it looks, feel free to visit https://hackclubos.netlify.app
